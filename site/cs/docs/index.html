Instalace a první spuštění

SetuHQ vyžaduje Python 3.11 nebo novější.

pip install "setuhq[tess] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq run configs/showcase/tess-wasp-126-s1.toml --out runs/tess-wasp-126-s1   # or any star: copy a config, change its TIC and sectors
setuhq crossmatch runs/tess-wasp-126-s1          # the NASA Exoplanet Archive's planets for the star
setuhq site runs/tess-wasp-126-s1 --out site     # a website from your run (several runs: list them all)

Každý příklad na tomto webu má svou konfiguraci v configs/ a svůj jednořádkový příkaz v docs/SHOWCASE.md. Běh stáhne světelnou křivku z MAST, vyčistí ji, nechá panel označit poklesy, prověří každý signál a zapíše každý výsledek s jeho původem. Probes běží bez účtu; Sentinels potřebují API klíč pro svého poskytovatele. Sentinels ve výchozím nastavení běží na Claude (Anthropic); další poskytovatelé jsou podporováni a označeni. Probes jsou deterministické detektory s přizpůsobeným filtrem.

Přispějte průzkumem

Prohledávání projde každý 2minutový cíl sektoru TESS a ponechá každý nalezený pokles, klasifikovaný, nic se nezahazuje. Můžete spustit část a poslat ji:

setuhq sweep configs/sweep.toml --sector 5 --limit 200 --workers 3
setuhq bundle my-sweep/sector_0005.json.gz --contributor "Your Name" --out bundle/

Open a pull request with the bundle. A maintainer checks it and merges it into Everything that dims, with your name on every entry it brings. See CONTRIBUTING.md.

Použití z AI asistenta (MCP)

pip install "setuhq[tess,mcp] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq-mcp --list-tools

Nastavení pro jednotlivé asistenty je v docs/MCP-INSTALL.md.

Data a soubory

  • Katalog známých planet (JSON) a všechny planety na mapě Galaxie (CSV), z exoplanet.eu.
  • Vše, co slábne (JSON): každá položka prohledávání SetuHQ s uvedením zdroje.
  • WASP-126 (Hot Jupiter): report běhu, tabule a spis běhu tess-wasp-126-s1.
  • TOI-270 (Multi-planet system): report běhu, tabule a spis běhu tess-toi-270-s5.
  • HD 15337 (Small planets near the limit): report běhu, tabule a spis běhu tess-hd-15337-s4.
  • TOI-236 (Known false positive): report běhu, tabule a spis běhu tess-toi-236-s2.
  • pi Men (Reference check): report běhu, tabule a spis běhu tess-pi-men-s1.
  • Benchmark, žebříček a článek: docs/ v repozitáři.

Vlastní data, benchmark, žebříček a článek SetuHQ jsou pod licencí CC BY 4.0; kód je pod licencí AGPL-3.0 (k dispozici je komerční licence). Citujte pomocí CITATION.cff.

Technické podrobnosti: odkud pocházejí grafy

Stránky kandidátů ukazují obrázky z uložených běhů (tess-wasp-126-s1, tess-toi-270-s5, tess-hd-15337-s4, tess-toi-236-s2, tess-pi-men-s1), vytvořené aktuálním kódem.

Every number on the candidate and evidence pages is read from stored files: the run directory, the search catalogue and the calibrated reviewer weights. Runs and configuration lists the files, the configuration and its hash.

Interaktivní části této stránky se nepodařilo načíst. Text výše je úplný; obnovte stránku a zkuste to znovu.
