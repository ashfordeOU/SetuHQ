Installation et première série

SetuHQ nécessite Python 3.11 ou plus récent.

pip install "setuhq[tess] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq run configs/showcase/tess-wasp-126-s1.toml --out runs/tess-wasp-126-s1   # or any star: copy a config, change its TIC and sectors
setuhq crossmatch runs/tess-wasp-126-s1          # the NASA Exoplanet Archive's planets for the star
setuhq site runs/tess-wasp-126-s1 --out site     # a website from your run (several runs: list them all)

Every example on this site has its configuration in configs/ and its one-line command in docs/SHOWCASE.md. The run downloads the light curve from MAST, cleans it, lets the panel mark dips, vets each signal and writes every result with its provenance. The Probes run with no account; the Sentinels need an API key for their provider. Sentinels run on Claude (Anthropic) by default; other providers are supported and labelled. Probes are deterministic matched-filter detectors.

Contribuer un balayage

A sweep searches every 2-minute target of a TESS sector and keeps every dip it finds, classified, with nothing thrown away. You can run a slice and send it in:

setuhq sweep configs/sweep.toml --sector 5 --limit 200 --workers 3
setuhq bundle my-sweep/sector_0005.json.gz --contributor "Your Name" --out bundle/

Open a pull request with the bundle. A maintainer checks it and merges it into Everything that dims, with your name on every entry it brings. See CONTRIBUTING.md.

L'utiliser depuis un assistant IA (MCP)

pip install "setuhq[tess,mcp] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq-mcp --list-tools

Set-up for each assistant is in docs/MCP-INSTALL.md.

Données et fichiers

  • The catalogue of known planets (JSON) and every planet on the Galaxy map (CSV), from exoplanet.eu.
  • Everything that dims (JSON): every entry of SetuHQ's sweep, with its credit.
  • WASP-126 (Hot Jupiter): le rapport de série, les planches et le dossier de la série tess-wasp-126-s1.
  • TOI-270 (Multi-planet system): le rapport de série, les planches et le dossier de la série tess-toi-270-s5.
  • HD 15337 (Small planets near the limit): le rapport de série, les planches et le dossier de la série tess-hd-15337-s4.
  • TOI-236 (Known false positive): le rapport de série, les planches et le dossier de la série tess-toi-236-s2.
  • pi Men (Reference check): le rapport de série, les planches et le dossier de la série tess-pi-men-s1.
  • The benchmark, the leaderboard and the paper: docs/ in the repository.

SetuHQ's own data, benchmark, leaderboard and paper are under CC BY 4.0; the code is under the AGPL-3.0 (a commercial licence is available). Cite it with CITATION.cff.

Détails techniques : d'où viennent les chiffres

The candidate pages show figures from the stored runs (tess-wasp-126-s1, tess-toi-270-s5, tess-hd-15337-s4, tess-toi-236-s2, tess-pi-men-s1), made with the current code.

Every number on the candidate and evidence pages is read from stored files: the run directory, the search catalogue and the calibrated reviewer weights. Runs and configuration lists the files, the configuration and its hash.
