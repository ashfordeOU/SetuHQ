ドキュメント

エディション。

エンジン全体が無料で、これからも無料です。Ashforde OÜ は機能制限ではなく、商用ライセンス、SetuHQ Pro、個別調査によってこれを支えています。このサイトに価格の掲載はなく、有料の道はすべてメッセージから始まります。

エディションを比べる

行に沿って読むと 3 つを比べられます。

オープンコア無料 · AGPL-3.0 または商用ライセンスSetuHQ Pro契約に基づき提供 · 開発中カスタム研究有償の受託作業
重要な理由

誰でもTESSの光度曲線を探索し、判定の背後にあるすべてのチェックを見て、数値を再現できる。オープンコアはエンジン全体であり、このサイトのすべてはその上で動いている。

機関が必要とするのは、公開リポジトリでは提供できないもの、すなわち規模、プライバシー、パッケージング、説明責任である。Pro が販売するのはそれらであり、より優れた科学ではない。Pro のすべての数値はオープンなエンジンから得られるものであり、そのエンジンは誰でも無料で再実行できる。

問いはあなたのものでも、時間がない場合：Ashforde OÜ があなたの問いでオープンなエンジンを実行し、無料のコードで再実行できる結果を返す。

対象とする利用者
  • 再実行・引用できる結果を必要とする研究者、学生、査読者
  • スイープを実行して提出するコントリビューター
  • MCPを介してSetuHQをコードやAIアシスタントに組み込む開発者
  • 公開まで成果を非公開にしておくフォローアップチームやミッションチーム
  • 凍結されたベンチマークでレビュアーを測定したいAIプロバイダーや研究グループ
  • 大学、プラネタリウム、アプリ開発者
  • セクタースイープや候補の調査資料を必要とするチーム
  • 検出数予測研究を求める装置チーム
含まれるもの
  • 探索、SentinelsとProbes、審査、トランジットフィット
  • 固定された実 TOI ベンチマークと公開リーダーボード
  • スイープ、MCPサーバー、このサイト、および単体のケースファイル、図版、レポート
  • フレア、脈動、公開されている CHEOPS の光度曲線（CHEOPS のデータは ESA の規約に従う）
  • Pro Calibrate 開発中: 固定された 662-TOI ベンチマークにおける AI レビュアーの較正証明書
  • Pro Workspace 開発中：非公開のターゲットリスト、公開制限付きの候補、チームのロール、監査証跡
  • Pro Sweeps 開発中：セクターまたはターゲットリストを対象としたホスト型の探索で、顧客自身の AI プロバイダキーを使用する。結果はオープンな貢献バンドルとして返される
  • Pro Follow-up 開発中：候補ごとのフォローアップパケット。ExoFOP形式のエクスポート、不確かさ付きのエフェメリス、そして顧客の望遠鏡からターゲットを観測できる時期を含む
  • Education & Dome 開発中：教室向けの検証演習とプラネタリウム版
  • 商用ライセンス & SDK 開発中：クローズドな製品に組み込むエンジン、安定した API 付き
  • セクター掃引、候補の資料、または提案中の観測装置の検出数予測
  • オープンなエンジンそのまま: 新しいコードはなく、すべての図はこのサイトと同様にラベル付けされている
  • 候補は候補のままである:研究は決して惑星の確認ではない
