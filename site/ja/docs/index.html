自分で動かす。

SetuHQ はオープンソースです。インストールして、このサイトが示すのと同じパネルで星の光度曲線を探索し、空のスイープを貢献し、あるいは AI アシスタントに使わせることができます。

はじめに

インストールしたら、このサイトの例の実行と同じように、任意の TESS の星の光度曲線を探索します。

インストールと初回の実行

SetuHQ には Python 3.11 以降が必要です。

pip install "setuhq[tess] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq run configs/showcase/tess-wasp-126-s1.toml --out runs/tess-wasp-126-s1   # or any star: copy a config, change its TIC and sectors
setuhq crossmatch runs/tess-wasp-126-s1          # the NASA Exoplanet Archive's planets for the star
setuhq site runs/tess-wasp-126-s1 --out site     # a website from your run (several runs: list them all)

このサイトのすべての例は、設定が configs/ に、1 行のコマンドが docs/SHOWCASE.md にある。実行すると MAST から光度曲線をダウンロードしてクリーニングし、パネルに減光をマークさせ、各シグナルを審査し、すべての結果を来歴とともに書き出す。Probes はアカウントなしで実行できる。Sentinels にはプロバイダーの API キーが必要である。Sentinels はデフォルトで Claude（Anthropic）上で動作する。他のプロバイダーにも対応しており、その旨が表示される。Probes は決定論的なマッチドフィルター検出器である。

スイープを貢献する

スイープはTESSセクターの2分ケイデンスの全ターゲットを探索し、見つかったすべての減光を分類して保持し、何も捨てない。一部を実行して送ることができる：

setuhq sweep configs/sweep.toml --sector 5 --limit 200 --workers 3
setuhq bundle my-sweep/sector_0005.json.gz --contributor "Your Name" --out bundle/

Open a pull request with the bundle. A maintainer checks it and merges it into Everything that dims, with your name on every entry it brings. See CONTRIBUTING.md.

AI アシスタントから使う (MCP)

pip install "setuhq[tess,mcp] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq-mcp --list-tools

各アシスタントの設定方法は docs/MCP-INSTALL.md にある。

データとファイル

  • 既知の惑星のカタログ（JSON）と銀河マップ上のすべての惑星（CSV）、exoplanet.eu より。
  • 減光するものすべて (JSON): SetuHQ の掃引の全エントリとそのクレジット。
  • WASP-126 (Hot Jupiter): 実行 tess-wasp-126-s1 の実行レポート、プレート、ケースファイル。
  • TOI-270 (Multi-planet system): 実行 tess-toi-270-s5 の実行レポート、プレート、ケースファイル。
  • HD 15337 (Small planets near the limit): 実行 tess-hd-15337-s4 の実行レポート、プレート、ケースファイル。
  • TOI-236 (Known false positive): 実行 tess-toi-236-s2 の実行レポート、プレート、ケースファイル。
  • pi Men (Reference check): 実行 tess-pi-men-s1 の実行レポート、プレート、ケースファイル。
  • ベンチマーク、リーダーボード、論文:リポジトリ内のdocs/。

SetuHQ 独自のデータ、ベンチマーク、リーダーボード、論文は CC BY 4.0 のもとで、コードは AGPL-3.0 のもとで公開されている（商用ライセンスも利用可能）。引用には CITATION.cff を使用すること。

技術的な詳細: 図の出どころ

候補のページには、保存された実行（tess-wasp-126-s1、tess-toi-270-s5、tess-hd-15337-s4、tess-toi-236-s2、tess-pi-men-s1）から現在のコードで作成した図を掲載している。

Every number on the candidate and evidence pages is read from stored files: the run directory, the search catalogue and the calibrated reviewer weights. Runs and configuration lists the files, the configuration and its hash.
