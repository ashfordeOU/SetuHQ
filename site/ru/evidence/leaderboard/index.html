Методы, оценённые вслепую на настоящих TOI.

Публичный рейтинг на замороженном бенчмарке настоящих TOI: обнаруженные события каждой заявки, оценённые самим рейтингом только на отложенной половине, с 95% интервалами Уилсона. Это не пороговый обзор внедрением (docs/threshold_sweep.md), который настраивает пороги Probe на синтетических кривых блеска.

Измерено на заявленном бенчмарке; ничто здесь не является открытием. Sentinels по умолчанию работают на Claude (Anthropic); другие поставщики поддерживаются и помечаются. Probes — детерминированные детекторы с согласованным фильтром.

Отложенная половина все отложенные звёзды

Бенчмарк не может показать, что Probes читают кривые блеска лучше, чем метаданные каталога предсказывают диспозиции (парная ΔJ (floor − Probes) = +0.039, 95% ДИ от -0,096 до +0.173, P(ΔJ ≤ 0) = 0,29).

Каждая ячейка: доля, затем k/n и 95% интервал Wilson, изображённый полосой от 0 до 100% (Youden J от −1 до +1, с отметкой на 0).

Строки Sentinel охватывают 37 звёзд. Их интервалы широки, две персоны используют одну модель (они согласны по 35 из 37 звёзд, φ = 0,88), поэтому они считаются одним коррелированным голосующим, а не двумя, и они никогда не запускались на контрольных кривых блеска. Строки Probes + Sentinels — это комбинации сохранённых результатов на уровне звёзд, заданные до оценки, а не запуск консенсуса панели.

Правила

  1. Оценивается только на отложенной половине замороженной выборки (TOI по чётности sha256(seed:TIC)); настроечная половина никогда не оценивается.
  2. Заявка перечисляет для каждой звезды из своего охвата события, обнаруженные её методом на реальной кривой блеска и на контрольных копиях с инвертированным и поблочно перемешанным потоком (время, длительность, период, собственный вердикт о прохождении и флаги). Таблица лидеров сама определяет, какие события лежат на эфемериде TOI (score_star и match_toi эталонного набора), и сама подсчитывает ложные срабатывания на контрольных данных. Самостоятельно заявленные результаты не принимаются.
  3. Ранжирование: J Юдена на доступном для поиска наборе, зафиксированном бенчмарком (звёзды с 2-минутной кривой блеска SPOC), с одним предикатом для обеих сторон — чистый кандидат (на эфемериде, прошёл проверку, без пометки затменной двойной): J = доля звёзд CP/KP, предложенных как чистые кандидаты, + доля звёзд FP, не предложенных, − 1, с интервалом Уилсона, объединённым методом «квадрат и сложение». Если называть каждый TOI планетой, с пометкой или без, получается J = 0; доступная для поиска звезда, отмеченная как непросмотренная, считается не предложенной. Рядом показан J по всем звёздам области. Там, где интервалы перекрываются, порядок не является измеренным различием.
  4. Контрольные наборы ограничивают ранжирование и не входят в J: ранжируются только отложенные записи с обоими контрольными списками для каждой исследованной звезды, остальные перечислены без ранга. Контрольные списки — собственный отчёт метода; таблица лидеров не может пересчитать их без кривых блеска. Подвыборка Sentinel никогда не ранжируется.
  5. Нижняя планка: базовая модель только по метаданным вообще не использует кривую блеска, а лишь публичный номер TOI, период, длительность, ошибки эфемерид и эпоху, с логистической регрессией, обученной на половине для настройки. Если метод её не превосходит, не показано, что он читает кривые блеска лучше, чем собственные метаданные каталога предсказывают диспозиции.
  6. В заявке указывается sha256 открытых входных данных, на которых она построена (настроечная половина с метками, отложенная половина без них). Любой другой хеш, tuned_on со значением, отличным от none или tuning, поле вне белого списка, отсутствующая или лишняя звезда либо отсутствие сведений о происхождении: отклоняется с перечислением причин.
  7. Хеш — это заверение: отложенные метки открыто лежат в репозитории, поэтому таблица лидеров не может доказать, что их не читали, а вердикты «пройдено» и контрольные события метода — это его собственный отчёт. Эти пробелы закрыли бы ложные кривые блеска, хранимые сопровождающими, и проспективная оценка на TOI, по которым ещё нет решения; ни того, ни другого пока нет.
  8. Отсев FP: звёзды с FP, чей провал TOI метод не предложил как чистый кандидат (восстановлен и не помечен). Надёжность: доля чистых кандидатов на провалах TOI, относящихся к CP/KP, при соотношении классов этой выборки, которое отличается от каталога TOI. Все доли приведены с 95% интервалами Wilson. Диспозиции TFOPWG служат эталоном, но не являются истиной в последней инстанции для каждого TOI.
  9. Измерено на заявленном бенчмарке; ничто в этой таблице лидеров не является открытием.

Формат отправки и правила отказа: docs/leaderboard/README.md. Оценить отправку: setuhq leaderboard <file>.
