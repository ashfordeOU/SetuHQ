31 провал, которые можно открыть, из 5 звёзд-примеров.

Провалы, которые панель отметила в кривой блеска TESS каждой звезды-примера, сгруппированные по звёздам и подсчитанные по результату проверки. Провал, прошедший проверку, — это кандидат, не подтверждён; помеченный — открыт; отклонённый — не кандидат. Ни один не является подтверждённой планетой. Откройте один, чтобы посмотреть его воспроизведение, или его дело с каждой проверкой за вердиктом. Ниже: 53 записей поисковой ленты с других звёзд, у которых ещё нет дела.

Из ленты поиска: записей — 53, других звёзд — 6

SetuHQ's search batches run the same panel over more TESS stars. These entries are leads for review: 53 of 53 match a known TOI period, and none has a case file yet. A TOI match is an archive comparison. Archive values only. This page claims no detection. The feed shows only signals that match a known TOI. Сигналы, не совпадающие ни с одним известным TOI, удерживаются для закрытого рассмотрения; их публикуют только после рассмотрения и сообщения.

Правило ленты. Запись попадает в ленту, если её глубина не превышает 5 000 ppm, а её сигнал содержит не менее 2 транзитов. Это правило допуска, а не результат проверки.

Глубина в зависимости от периода

Каждая точка — запись ленты; размер и свечение зависят от SNR; жёлтый: нет известного периода TOI. Только архивные значения. Эта страница не заявляет ни об одном обнаружении.
