Установка и первый запуск

SetuHQ требуется Python 3.11 или новее.

pip install "setuhq[tess] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq run configs/showcase/tess-wasp-126-s1.toml --out runs/tess-wasp-126-s1   # or any star: copy a config, change its TIC and sectors
setuhq crossmatch runs/tess-wasp-126-s1          # the NASA Exoplanet Archive's planets for the star
setuhq site runs/tess-wasp-126-s1 --out site     # a website from your run (several runs: list them all)

У каждого примера на этом сайте есть конфигурация в configs/ и однострочная команда в docs/SHOWCASE.md. Запуск загружает кривую блеска из MAST, очищает её, позволяет панели отмечать провалы, проверяет каждый сигнал и записывает каждый результат с указанием происхождения. Probes работают без учётной записи; Sentinels требуют API-ключ своего провайдера. По умолчанию Sentinels работают на Claude (Anthropic); другие провайдеры поддерживаются и помечены. Probes — детерминированные детекторы на основе согласованного фильтра.

Добавьте обзор

Прогон просматривает каждую 2-минутную цель сектора TESS и сохраняет каждый найденный провал с классификацией, ничего не отбрасывая. Вы можете запустить часть и прислать её:

setuhq sweep configs/sweep.toml --sector 5 --limit 200 --workers 3
setuhq bundle my-sweep/sector_0005.json.gz --contributor "Your Name" --out bundle/

Open a pull request with the bundle. A maintainer checks it and merges it into Everything that dims, with your name on every entry it brings. See CONTRIBUTING.md.

Использование из ИИ-ассистента (MCP)

pip install "setuhq[tess,mcp] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq-mcp --list-tools

Настройка для каждого ассистента описана в docs/MCP-INSTALL.md.

Данные и файлы

  • Каталог известных планет (JSON) и все планеты на карте Галактики (CSV), из exoplanet.eu.
  • Всё, что тускнеет (JSON): каждая запись обзора SetuHQ с указанием авторства.
  • WASP-126 (Hot Jupiter): отчёт о запуске, таблицы и дело запуска tess-wasp-126-s1.
  • TOI-270 (Multi-planet system): отчёт о запуске, таблицы и дело запуска tess-toi-270-s5.
  • HD 15337 (Small planets near the limit): отчёт о запуске, таблицы и дело запуска tess-hd-15337-s4.
  • TOI-236 (Known false positive): отчёт о запуске, таблицы и дело запуска tess-toi-236-s2.
  • pi Men (Reference check): отчёт о запуске, таблицы и дело запуска tess-pi-men-s1.
  • Бенчмарк, таблица лидеров и статья: docs/ в репозитории.

Собственные данные, бенчмарк, таблица лидеров и статья SetuHQ распространяются по CC BY 4.0; код — по AGPL-3.0 (доступна коммерческая лицензия). Для цитирования используйте CITATION.cff.

Технические подробности: откуда берутся графики

На страницах кандидатов показаны рисунки из сохранённых запусков (tess-wasp-126-s1, tess-toi-270-s5, tess-hd-15337-s4, tess-toi-236-s2, tess-pi-men-s1), построенные текущей версией кода.

Every number on the candidate and evidence pages is read from stored files: the run directory, the search catalogue and the calibrated reviewer weights. Runs and configuration lists the files, the configuration and its hash.
