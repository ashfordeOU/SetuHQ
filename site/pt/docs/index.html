Instalação e primeira execução

O SetuHQ precisa do Python 3.11 ou mais recente.

pip install "setuhq[tess] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq run configs/showcase/tess-wasp-126-s1.toml --out runs/tess-wasp-126-s1   # or any star: copy a config, change its TIC and sectors
setuhq crossmatch runs/tess-wasp-126-s1          # the NASA Exoplanet Archive's planets for the star
setuhq site runs/tess-wasp-126-s1 --out site     # a website from your run (several runs: list them all)

Cada exemplo neste site tem a sua configuração em configs/ e o seu comando de uma linha em docs/SHOWCASE.md. A execução descarrega a curva de luz do MAST, limpa-a, deixa o painel marcar as quedas, verifica cada sinal e escreve cada resultado com a sua proveniência. Os Probes funcionam sem conta; os Sentinels precisam de uma chave de API para o seu fornecedor. Os Sentinels funcionam com Claude (Anthropic) por predefinição; outros fornecedores são suportados e identificados. Os Probes são detetores determinísticos de filtro adaptado.

Contribuir com uma varredura

Uma varredura pesquisa todos os alvos de 2 minutos de um setor TESS e guarda cada queda que encontra, classificada, sem descartar nada. Pode executar uma fatia e enviá-la:

setuhq sweep configs/sweep.toml --sector 5 --limit 200 --workers 3
setuhq bundle my-sweep/sector_0005.json.gz --contributor "Your Name" --out bundle/

Open a pull request with the bundle. A maintainer checks it and merges it into Everything that dims, with your name on every entry it brings. See CONTRIBUTING.md.

Usar a partir de um assistente de IA (MCP)

pip install "setuhq[tess,mcp] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq-mcp --list-tools

A configuração para cada assistente está em docs/MCP-INSTALL.md.

Dados e arquivos

  • O catálogo de planetas conhecidos (JSON) e todos os planetas no mapa da Galáxia (CSV), a partir do exoplanet.eu.
  • Tudo o que diminui de brilho (JSON): todas as entradas da varredura do SetuHQ, com o respetivo crédito.
  • WASP-126 (Hot Jupiter): o relatório da execução, as pranchas e o dossiê da execução tess-wasp-126-s1.
  • TOI-270 (Multi-planet system): o relatório da execução, as pranchas e o dossiê da execução tess-toi-270-s5.
  • HD 15337 (Small planets near the limit): o relatório da execução, as pranchas e o dossiê da execução tess-hd-15337-s4.
  • TOI-236 (Known false positive): o relatório da execução, as pranchas e o dossiê da execução tess-toi-236-s2.
  • pi Men (Reference check): o relatório da execução, as pranchas e o dossiê da execução tess-pi-men-s1.
  • O benchmark, a tabela classificativa e o artigo: docs/ no repositório.

Os dados, o benchmark, a tabela de classificação e o artigo do próprio SetuHQ estão sob CC BY 4.0; o código está sob a AGPL-3.0 (está disponível uma licença comercial). Cite-o com CITATION.cff.

Detalhes técnicos: de onde vêm os números

As páginas dos candidatos mostram figuras das execuções armazenadas (tess-wasp-126-s1, tess-toi-270-s5, tess-hd-15337-s4, tess-toi-236-s2, tess-pi-men-s1), produzidas com o código atual.

Every number on the candidate and evidence pages is read from stored files: the run directory, the search catalogue and the calibrated reviewer weights. Runs and configuration lists the files, the configuration and its hash.
