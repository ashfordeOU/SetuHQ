Установлення та перший запуск

SetuHQ потребує Python 3.11 або новішого.

pip install "setuhq[tess] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq run configs/showcase/tess-wasp-126-s1.toml --out runs/tess-wasp-126-s1   # or any star: copy a config, change its TIC and sectors
setuhq crossmatch runs/tess-wasp-126-s1          # the NASA Exoplanet Archive's planets for the star
setuhq site runs/tess-wasp-126-s1 --out site     # a website from your run (several runs: list them all)

Конфігурація кожного прикладу на цьому сайті міститься в configs/, а його однорядкова команда — в docs/SHOWCASE.md. Запуск завантажує криву блиску з MAST, очищує її, дає панелі позначити падіння, перевіряє кожен сигнал і записує кожен результат із його походженням. Probes працюють без облікового запису; Sentinels потребують API-ключа свого провайдера. За замовчуванням Sentinels працюють на Claude (Anthropic); інші провайдери підтримуються та позначаються. Probes — детерміновані детектори з узгодженим фільтром.

Додайте огляд

Прогін шукає в кожній 2-хвилинній цілі сектору TESS і зберігає кожен знайдений провал, класифікований, нічого не відкидаючи. Ви можете запустити частину й надіслати її:

setuhq sweep configs/sweep.toml --sector 5 --limit 200 --workers 3
setuhq bundle my-sweep/sector_0005.json.gz --contributor "Your Name" --out bundle/

Open a pull request with the bundle. A maintainer checks it and merges it into Everything that dims, with your name on every entry it brings. See CONTRIBUTING.md.

Використання з ШІ-асистента (MCP)

pip install "setuhq[tess,mcp] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq-mcp --list-tools

Налаштування для кожного асистента описано в docs/MCP-INSTALL.md.

Дані та файли

  • Каталог відомих планет (JSON) і кожна планета на мапі Галактики (CSV), з exoplanet.eu.
  • Усе, що тьмяніє (JSON): кожен запис огляду SetuHQ із зазначенням авторства.
  • WASP-126 (Hot Jupiter): звіт про запуск, таблиці і справа запуску tess-wasp-126-s1.
  • TOI-270 (Multi-planet system): звіт про запуск, таблиці і справа запуску tess-toi-270-s5.
  • HD 15337 (Small planets near the limit): звіт про запуск, таблиці і справа запуску tess-hd-15337-s4.
  • TOI-236 (Known false positive): звіт про запуск, таблиці і справа запуску tess-toi-236-s2.
  • pi Men (Reference check): звіт про запуск, таблиці і справа запуску tess-pi-men-s1.
  • Бенчмарк, таблиця лідерів і стаття: docs/ у репозиторії.

Власні дані, бенчмарк, таблиця лідерів і стаття SetuHQ поширюються за CC BY 4.0; код — за AGPL-3.0 (доступна комерційна ліцензія). Цитуйте за допомогою CITATION.cff.

Технічні подробиці: звідки беруться графіки

Сторінки кандидатів показують рисунки зі збережених запусків (tess-wasp-126-s1, tess-toi-270-s5, tess-hd-15337-s4, tess-toi-236-s2, tess-pi-men-s1), створені поточним кодом.

Every number on the candidate and evidence pages is read from stored files: the run directory, the search catalogue and the calibrated reviewer weights. Runs and configuration lists the files, the configuration and its hash.

Інтерактивні частини цієї сторінки не завантажилися. Текст вище повний; перезавантажте, щоб спробувати ще раз.
