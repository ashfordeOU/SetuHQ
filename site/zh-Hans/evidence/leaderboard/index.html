规则

  1. 仅在冻结样本的留出半数上评分（按 sha256(seed:TIC) 奇偶性划分 TOI）；调参半数从不评分。
  2. 提交内容需针对其范围内的每颗恒星，列出其方法在真实光变曲线以及通量翻转和分块打乱的对照数据上检出的事件（时间、持续时间、周期、其自身的通过判定和标记）。排行榜自行判定哪些事件位于该 TOI 的星历上（基准的 score_star 和 match_toi），并自行统计对照数据中的误报。不接受自行报告的结果。
  3. 排名：在基准测试固定的可搜索集合（拥有 SPOC 2 分钟光变曲线的恒星）上计算 Youden's J，两侧使用同一判定条件，即干净候选（符合星历、已通过、无食双星标记）：J = 作为干净候选给出的 CP/KP 恒星比例 + 未给出的 FP 恒星比例 − 1，并附平方相加 Wilson 区间。把每个 TOI 都判为行星（无论有无标记）得分 J = 0；被判为未搜索的可搜索恒星计为未给出。旁边显示了覆盖范围内全部恒星的 J。区间重叠时，排序并不代表测得的差异。
  4. 对照项控制是否参与排名，但不计入 J：只有在每颗被搜索恒星上都具备两份对照列表的留出条目才会被排名，其余条目列出但不排名。对照列表由方法自行报告；没有光变曲线，排行榜无法重新计算它们。Sentinel 子样本从不参与排名。
  5. 基准下限：仅用元数据的基线完全不使用光变曲线，只用公开的 TOI 编号、周期、持续时间、星历误差和历元，并在调参半数据上拟合逻辑回归。一个方法若不能胜过它，就不能表明它读取光变曲线的能力强于目录自身元数据对处置结果的预测。
  6. 提交需注明其所依据公开输入的 sha256（调参半样本含标签，留出半样本不含标签）。任何其他哈希值、tuned_on 不为 none 或 tuning、白名单之外的字段、缺失或多出的恒星，或缺少来源信息：均会被拒绝，并列出原因。
  7. 该哈希只是一种声明：留出集标签在仓库中公开，因此排行榜无法证明它们未被读取，而方法的通过判定和对照事件均为其自行报告。由维护者持有的诱饵光变曲线，以及对尚未处置的 TOI 进行前瞻性评分，可以弥补这些缺口；但两者目前都尚不存在。
  8. FP 否决：其 TOI 下陷未被该方法作为干净候选给出的 FP 恒星（已找回且未标为待复核）。可靠性：TOI 下陷上的干净候选中属于 CP/KP 的比例，基于本样本的类别构成，而非 TOI 星表的类别构成。所有比率均附 Wilson 95% 区间。TFOPWG 处置结论仅作参考，并非对每个 TOI 都是真实情况。
  9. 在一个明确说明的基准上测得；本排行榜上的任何结果都不是发现。

提交格式和拒收规则：docs/leaderboard/README.md。使用 setuhq leaderboard <file> 为提交评分。
