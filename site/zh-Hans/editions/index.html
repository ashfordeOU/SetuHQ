逐行阅读以比较三者。

开放核心免费 · AGPL-3.0 或商业许可SetuHQ Pro按合同提供 · 开发中定制研究付费服务，由我们代为完成
为何重要

任何人都可以搜索 TESS 光变曲线，查看每个判定背后的所有检验，并重现这些数字。开源核心就是整个引擎，本站的一切都运行在它之上。

机构需要公共代码库无法提供的东西：规模、隐私、打包和问责。Pro 出售的是这些，而绝非更好的科学：Pro 的每个数字都将来自开源引擎，任何人都可以免费重新运行。

问题是您的，但没有时间时：Ashforde OÜ 用开源引擎处理您的问题，并交付一个可用免费代码重新运行的结果。

面向谁
  • 需要可重新运行和可引用结果的研究人员、学生和审稿人
  • 运行巡查并提交结果的贡献者
  • 通过 MCP 将 SetuHQ 接入代码或 AI 助手的开发者
  • 在发布前对工作保密的后续观测团队和任务团队
  • 希望在冻结基准上测量审查器表现的 AI 提供商和研究团队
  • 大学、天文馆和应用开发者
  • 需要扇区扫描或候选档案的团队
  • 需要行星产出研究的仪器团队
包含内容
  • 搜索、Sentinels 与 Probes、审查与凌星拟合
  • 冻结的真实 TOI 基准与公开排行榜
  • 扫描、MCP 服务器、本网站，以及独立的案例文件、图版和报告
  • 耀斑、脉动和公开的 CHEOPS 光变曲线（CHEOPS 数据遵循 ESA 的条款）
  • Pro Calibrate 开发中：针对 AI 审核者、基于冻结的 662 个 TOI 基准的校准证书
  • Pro 工作区 开发中：私有目标列表、保密期内的候选、团队角色和审计追踪
  • Pro Sweeps 开发中：针对多个扇区或目标列表的托管搜索，使用客户自己的 AI 服务商密钥；结果以开放贡献包的形式返回
  • Pro Follow-up 开发中：为每个候选提供后续观测数据包：ExoFOP 风格的导出、附带不确定度的星历，以及目标何时可从客户的望远镜观测
  • 教育与球幕 开发中：课堂审查练习和天象馆版本
  • 商业许可 & SDK 开发中：嵌入闭源产品的引擎，提供稳定的 API
  • 一次扇区扫描、一份候选档案，或针对拟议仪器的产出研究
  • 开放引擎的原样：没有新代码，每幅图都按本站的方式标注
  • 候选始终是候选：研究绝不等于对行星的确认
