Twenty-six days of pi Men.
One planet found again. One dip unexplained.

3,485 stored brightness measurements over 26.0 days. The panel, 2 Sentinels and 3 Probes (no people), marked 7 dips, which the vetting code grouped into 3 signals: 1 passed, 1 flagged, 1 rejected. Each dip is this pipeline's own candidate, unconfirmed as an independent detection; the archive match says the planet is already known, not that this run confirmed it. The stored archive cross-match (the repository's stored copy) finds the lead signal consistent with pi Men c, a published planet: a known planet, not a discovery. Archive values only. This page claims no detection.
