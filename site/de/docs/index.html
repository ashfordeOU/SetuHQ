Installation und erster Lauf

SetuHQ benötigt Python 3.11 oder neuer.

pip install "setuhq[tess] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq run configs/showcase/tess-wasp-126-s1.toml --out runs/tess-wasp-126-s1   # or any star: copy a config, change its TIC and sectors
setuhq crossmatch runs/tess-wasp-126-s1          # the NASA Exoplanet Archive's planets for the star
setuhq site runs/tess-wasp-126-s1 --out site     # a website from your run (several runs: list them all)

Jedes Beispiel auf dieser Website hat seine Konfiguration in configs/ und seinen einzeiligen Befehl in docs/SHOWCASE.md. Der Lauf lädt die Lichtkurve von MAST herunter, bereinigt sie, lässt das Panel Einbrüche markieren, prüft jedes Signal und schreibt jedes Ergebnis mit seiner Herkunft. Die Probes laufen ohne Konto; die Sentinels benötigen einen API-Schlüssel für ihren Anbieter. Sentinels laufen standardmäßig auf Claude (Anthropic); andere Anbieter werden unterstützt und gekennzeichnet. Probes sind deterministische Matched-Filter-Detektoren.

Einen Sweep beitragen

Ein Sweep durchsucht jedes 2-Minuten-Ziel eines TESS-Sektors und behält jeden gefundenen Einbruch, klassifiziert, ohne dass etwas weggeworfen wird. Sie können einen Teil ausführen und einsenden:

setuhq sweep configs/sweep.toml --sector 5 --limit 200 --workers 3
setuhq bundle my-sweep/sector_0005.json.gz --contributor "Your Name" --out bundle/

Open a pull request with the bundle. A maintainer checks it and merges it into Everything that dims, with your name on every entry it brings. See CONTRIBUTING.md.

Aus einem KI-Assistenten nutzen (MCP)

pip install "setuhq[tess,mcp] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq-mcp --list-tools

Die Einrichtung für jeden Assistenten ist in docs/MCP-INSTALL.md beschrieben.

Technische Details: woher die Zahlen kommen

Die Kandidatenseiten zeigen Abbildungen aus den gespeicherten Läufen (tess-wasp-126-s1, tess-toi-270-s5, tess-hd-15337-s4, tess-toi-236-s2, tess-pi-men-s1), erstellt mit dem aktuellen Code.

Every number on the candidate and evidence pages is read from stored files: the run directory, the search catalogue and the calibrated reviewer weights. Runs and configuration lists the files, the configuration and its hash.
