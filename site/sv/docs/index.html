Installation och första körning

SetuHQ kräver Python 3.11 eller senare.

pip install "setuhq[tess] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq run configs/showcase/tess-wasp-126-s1.toml --out runs/tess-wasp-126-s1   # or any star: copy a config, change its TIC and sectors
setuhq crossmatch runs/tess-wasp-126-s1          # the NASA Exoplanet Archive's planets for the star
setuhq site runs/tess-wasp-126-s1 --out site     # a website from your run (several runs: list them all)

Varje exempel på denna webbplats har sin konfiguration i configs/ och sitt enradskommando i docs/SHOWCASE.md. Körningen hämtar ljuskurvan från MAST, rensar den, låter panelen markera dippar, granskar varje signal och skriver varje resultat med dess härkomst. Probes körs utan konto; Sentinels behöver en API-nyckel för sin leverantör. Sentinels körs som standard på Claude (Anthropic); andra leverantörer stöds och är märkta. Probes är deterministiska detektorer med anpassat filter.

Bidra med ett svep

Ett svep söker igenom varje 2-minutersmål i en TESS-sektor och behåller varje dipp det hittar, klassificerad, utan att något kastas bort. Du kan köra en del och skicka in den:

setuhq sweep configs/sweep.toml --sector 5 --limit 200 --workers 3
setuhq bundle my-sweep/sector_0005.json.gz --contributor "Your Name" --out bundle/

Open a pull request with the bundle. A maintainer checks it and merges it into Everything that dims, with your name on every entry it brings. See CONTRIBUTING.md.

Använd det från en AI-assistent (MCP)

pip install "setuhq[tess,mcp] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq-mcp --list-tools

Konfiguration för varje assistent finns i docs/MCP-INSTALL.md.

Data och filer

  • Katalogen över kända planeter (JSON) och varje planet på Galaxkartan (CSV), från exoplanet.eu.
  • Allt som mörknar (JSON): varje post i SetuHQ:s genomsökning, med sin källhänvisning.
  • WASP-126 (Hot Jupiter): körningsrapporten, planscherna och ärendeakten för körning tess-wasp-126-s1.
  • TOI-270 (Multi-planet system): körningsrapporten, planscherna och ärendeakten för körning tess-toi-270-s5.
  • HD 15337 (Small planets near the limit): körningsrapporten, planscherna och ärendeakten för körning tess-hd-15337-s4.
  • TOI-236 (Known false positive): körningsrapporten, planscherna och ärendeakten för körning tess-toi-236-s2.
  • pi Men (Reference check): körningsrapporten, planscherna och ärendeakten för körning tess-pi-men-s1.
  • Benchmarken, topplistan och artikeln: docs/ i arkivet.

SetuHQ:s egna data, benchmark, topplista och artikel omfattas av CC BY 4.0; koden omfattas av AGPL-3.0 (en kommersiell licens finns tillgänglig). Citera den med CITATION.cff.

Tekniska detaljer: var siffrorna kommer ifrån

Kandidatsidorna visar figurer från de lagrade körningarna (tess-wasp-126-s1, tess-toi-270-s5, tess-hd-15337-s4, tess-toi-236-s2, tess-pi-men-s1), gjorda med den nuvarande koden.

Every number on the candidate and evidence pages is read from stored files: the run directory, the search catalogue and the calibrated reviewer weights. Runs and configuration lists the files, the configuration and its hash.
