Feed

The feed from the discovery catalogue: 28 entries, 25 of them match a known TOI period. Every entry is a candidate, unconfirmed: a dip the panel marked, not a planet.

Feed rule (discover.py): an entry joins the feed when its depth is at most 5,000 ppm and its signal has at least 2 transits. This is an admission rule, not a vetting result.

Planets

One card per star in the run or the feed. Each entry is a candidate, unconfirmed; the ratio below is what its stored depth implies if it were a planet.

Radius ratio only. Rp/R* = √depth, with depth as a fraction (ppm × 10⁻⁶). This assumes a full, undiluted transit and ignores limb darkening. No stellar radius is stored in the run or the catalogue, so this page does not convert the ratio to a planet radius in Earth or Jupiter units. Each bar is a ratio scale from 0 to 0.10, the same on every card.

Published planets come from the stored archive cross-match (crossmatch.json), which covers TIC 261136679. The other stars have no stored cross-match, so their cards have no archive box. Archive values only. This page claims no detection.

Panel

The reviewers that marked dips in run tess-pi-men-s1. Simulated reviewers are code; Claude reviewers are model calls. None of them is a person.

Weights. A reviewer's weight is its calibration skill from injection tests: the true-positive rate on injected transits minus the false-positive rate on empty light curves, floored (calibrate.py). The calibrated weights are stored in docs/results/reviewer_weights_full_panel.json. The weight in this run is the one manifest.json records; when it differs from the calibrated weight, the run did not use the calibrated weights.
