What this page does not claim

  • No confirmed planet. Every dip, signal and feed entry here is a candidate, unconfirmed. Passing vetting is not a confirmation. The match with pi Men c says the planet is already known, not that this run confirmed it.
  • No planet sizes. No stellar radius is stored, so a depth gives only a planet-to-star radius ratio. The Planets page shows the working.
  • No people on the panel. The panel is the Sentinels and the Probes: 2 Sentinels and 3 Probes. Sentinels run on Claude (Anthropic). Probes are deterministic matched-filter detectors. Their weights rest on calibration with 10 planted and 10 empty light curves each, so they are rough.
  • Archive values only. This page claims no detection. A TOI or archive match compares a stored period with published values.
  • No image of the planet. The planet on the Overview is an artist's impression; the field stars on the sky map are decorative.

Twenty-six days of pi Men.
One planet found again. One dip unexplained.

3,485 stored brightness measurements over 26.0 days. The panel, 2 Sentinels and 3 Probes (no people), marked 7 dips, which the vetting code grouped into 3 signals: 1 passed, 1 flagged, 1 rejected. Each dip is this pipeline's own candidate, unconfirmed as an independent detection; the archive match says the planet is already known, not that this run confirmed it. The stored archive cross-match (docs/results/pi_men_crossmatch.json) finds the lead signal consistent with pi Men c, a published planet: a known planet, not a discovery. Archive values only. Sentinels and Probes

Five reviewers.
Each one earns its vote.

The panel that marked dips in run tess-pi-men-s1: the Sentinels and the Probes, no people. Sentinels run on Claude (Anthropic). Probes are deterministic matched-filter detectors.

Sentinels run on Claude (Anthropic). Probes are deterministic matched-filter detectors. Weights come from 10 planted and 10 empty light curves each: too few to separate 0.6 from 0.5.

Weights. A reviewer's weight is its calibration skill from injection tests: the true-positive rate on injected transits minus the false-positive rate on empty light curves, floored (calibrate.py). The calibrated weights are stored in docs/results/reviewer_weights_full_panel.json. The weight in this run is the one manifest.json records; when it differs from the calibrated weight, the run did not use the calibrated weights.

Calibration plane

Each reviewer at its false-alarm rate (x: share of empty subjects it marked) and recall (y: share of injected transits it found) in calibration. Point size is its calibrated weight. The lines join points of equal weight, weight = TPR − FPR, floored at 0.05; up and to the left is better. Stored values only.

Explorer ›Planets

What each depth would imply, if it were a planet.

One card per star in the run or the feed. Each entry is a candidate, unconfirmed; the ratio below is what its stored depth implies if it were a planet.

Radius ratio only. Rp/R* = √depth, with depth as a fraction (ppm × 10⁻⁶). This assumes a full, undiluted transit and ignores limb darkening. No stellar radius is stored in the run or the catalogue, so this page does not convert the ratio to a planet radius in Earth or Jupiter units. Each bar is a ratio scale from 0 to 0.10, the same on every card.

Published planets come from the stored archive cross-match (docs/results/pi_men_crossmatch.json), which covers TIC 261136679. The other stars have no stored cross-match, so their cards have no archive box. Archive values only. This page claims no detection.
