Installation og første kørsel

SetuHQ kræver Python 3.11 eller nyere.

pip install "setuhq[tess] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq run configs/showcase/tess-wasp-126-s1.toml --out runs/tess-wasp-126-s1   # or any star: copy a config, change its TIC and sectors
setuhq crossmatch runs/tess-wasp-126-s1          # the NASA Exoplanet Archive's planets for the star
setuhq site runs/tess-wasp-126-s1 --out site     # a website from your run (several runs: list them all)

Hvert eksempel på dette site har sin konfiguration i configs/ og sin kommando på én linje i docs/SHOWCASE.md. Kørslen downloader lyskurven fra MAST, renser den, lader panelet markere dyk, vurderer hvert signal og skriver hvert resultat med dets oprindelse. Probes kører uden konto; Sentinels kræver en API-nøgle til deres udbyder. Sentinels kører som standard på Claude (Anthropic); andre udbydere understøttes og er mærket. Probes er deterministiske matched-filter-detektorer.

Bidrag med en gennemsøgning

En gennemsøgning gennemsøger hvert 2-minutters mål i en TESS-sektor og beholder hvert dyk, den finder, klassificeret, uden at noget kasseres. Du kan køre et udsnit og indsende det:

setuhq sweep configs/sweep.toml --sector 5 --limit 200 --workers 3
setuhq bundle my-sweep/sector_0005.json.gz --contributor "Your Name" --out bundle/

Open a pull request with the bundle. A maintainer checks it and merges it into Everything that dims, with your name on every entry it brings. See CONTRIBUTING.md.

Brug det fra en AI-assistent (MCP)

pip install "setuhq[tess,mcp] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq-mcp --list-tools

Opsætning for hver assistent findes i docs/MCP-INSTALL.md.

Data og filer

  • Kataloget over kendte planeter (JSON) og alle planeter på Galaksekortet (CSV), fra exoplanet.eu.
  • Alt, der dæmpes (JSON): hver post i SetuHQ's gennemsøgning med dens kreditering.
  • WASP-126 (Hot Jupiter): kørselsrapporten, pladerne og sagsmappen for kørsel tess-wasp-126-s1.
  • TOI-270 (Multi-planet system): kørselsrapporten, pladerne og sagsmappen for kørsel tess-toi-270-s5.
  • HD 15337 (Small planets near the limit): kørselsrapporten, pladerne og sagsmappen for kørsel tess-hd-15337-s4.
  • TOI-236 (Known false positive): kørselsrapporten, pladerne og sagsmappen for kørsel tess-toi-236-s2.
  • pi Men (Reference check): kørselsrapporten, pladerne og sagsmappen for kørsel tess-pi-men-s1.
  • Benchmarket, ranglisten og artiklen: docs/ i repositoriet.

SetuHQ's egne data, benchmark, rangliste og artikel er under CC BY 4.0; koden er under AGPL-3.0 (en kommerciel licens er tilgængelig). Citér den med CITATION.cff.

Tekniske detaljer: hvor tallene kommer fra

Kandidatsiderne viser figurer fra de lagrede kørsler (tess-wasp-126-s1, tess-toi-270-s5, tess-hd-15337-s4, tess-toi-236-s2, tess-pi-men-s1), lavet med den nuværende kode.

Every number on the candidate and evidence pages is read from stored files: the run directory, the search catalogue and the calibrated reviewer weights. Runs and configuration lists the files, the configuration and its hash.

Sidens interaktive dele kunne ikke indlæses. Teksten ovenfor er fuldstændig; genindlæs for at prøve igen.
