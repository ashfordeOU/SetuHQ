How a run works

1 · IngestTESS SPOC from MAST or CHEOPS FITS, time system kept as delivered
→
2 · Clean & detrendSpike clip, masked local-quadratic baseline, 10-min bins
→
3 · Blind subjects13-day segments with opaque IDs. The target name never reaches a reviewer
→
4 · Review panelEach subject marked and labelled by every reviewer, independently
→
5 · ConsensusClustered marks, skill-weighted score, panel must say "potential planet"
→
6 · VetSNR, duration, edges, odd/even depth, secondary eclipse, ephemeris fit

Thresholds, weights and every input are written to manifest.json, so a result can be rerun exactly.

Run runs/tess-pi-men-s1 (TESS SPOC sector 1, 10-minute bins), run on the current code (scripts/rerun_pi_men.py), with the limb-darkened fit (src/setuhq/transitfit.py). 5 of 5 predicted epochs are recovered by the panel. Limb darkening: Claret 2017 TESS quadratic u₁ = 0.341, u₂ = 0.224 for the TIC's Teff 5992 K and log g 4.36. Reference: NASA Exoplanet Archive, table ps, pl_name = 'pi Men c', fetched 2026-10-19 (docs/results/pi_men_reference.json).
