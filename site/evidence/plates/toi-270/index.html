SetuHQ plates: TOI-270

7 dips (5 candidates, 2 flagged) on 1 star, one plate per star, from run tess-toi-270-s5. Each dip that passed vetting is a candidate, unconfirmed, and is tagged so; a rejected or flagged dip is named by its status alone. Every number is a stored value.

  • BLS periods and epochs are found per 13-day subject (a fixed-length cut of a sector), not per sector.
  • The panel is the Sentinels and the Probes, no people. Sentinels run on Claude (Anthropic) by default; other providers are supported and labelled. Probes are deterministic matched-filter detectors. A dip's consensus interval is where their marks agree. Probes only; Sentinels not run on this example.
  • No stellar radius is stored, so no depth on this page is converted to a planet radius.
  • What this run did not recover: Found all 5 of c's transits and both of d's; b not found; d seen twice, no period (one transit per 13-day piece of the light curve).
  • Status is written as a word beside every colour.
