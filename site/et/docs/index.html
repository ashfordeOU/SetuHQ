Paigaldus ja esimene käitus

SetuHQ vajab Pythonit 3.11 või uuemat.

pip install "setuhq[tess] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq run configs/showcase/tess-wasp-126-s1.toml --out runs/tess-wasp-126-s1   # or any star: copy a config, change its TIC and sectors
setuhq crossmatch runs/tess-wasp-126-s1          # the NASA Exoplanet Archive's planets for the star
setuhq site runs/tess-wasp-126-s1 --out site     # a website from your run (several runs: list them all)

Igal selle saidi näitel on konfiguratsioon kaustas configs/ ja üherealine käsk failis docs/SHOWCASE.md. Jooks laadib valguskõvera alla MAST-ist, puhastab selle, laseb paneelil langusi märkida, kontrollib iga signaali ja kirjutab iga tulemuse koos selle päritoluga. Probes töötavad ilma kontota; Sentinels vajavad oma teenusepakkuja API-võtit. Sentinels töötavad vaikimisi Claude'il (Anthropic); toetatud on ka teised pakkujad ja need on märgistatud. Probes on deterministlikud sobitatud filtri detektorid.

Panusta läbivaatusse

Sõelumine otsib läbi TESS-i sektori iga 2-minutilise sihtmärgi ja säilitab iga leitud languse klassifitseerituna, midagi ära viskamata. Võid käivitada osa sellest ja selle sisse saata:

setuhq sweep configs/sweep.toml --sector 5 --limit 200 --workers 3
setuhq bundle my-sweep/sector_0005.json.gz --contributor "Your Name" --out bundle/

Open a pull request with the bundle. A maintainer checks it and merges it into Everything that dims, with your name on every entry it brings. See CONTRIBUTING.md.

Kasuta tehisintellekti assistendist (MCP)

pip install "setuhq[tess,mcp] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq-mcp --list-tools

Iga assistendi seadistus on failis docs/MCP-INSTALL.md.

Andmed ja failid

  • Teadaolevate planeetide kataloog (JSON) ja kõik Galaktika kaardi planeedid (CSV), allikas exoplanet.eu.
  • Kõik, mis tuhmub (JSON): iga SetuHQ ülevaatuse kirje koos viitega.
  • WASP-126 (Hot Jupiter): käituse tess-wasp-126-s1 käituse aruanne, tahvlid ja toimik.
  • TOI-270 (Multi-planet system): käituse tess-toi-270-s5 käituse aruanne, tahvlid ja toimik.
  • HD 15337 (Small planets near the limit): käituse tess-hd-15337-s4 käituse aruanne, tahvlid ja toimik.
  • TOI-236 (Known false positive): käituse tess-toi-236-s2 käituse aruanne, tahvlid ja toimik.
  • pi Men (Reference check): käituse tess-pi-men-s1 käituse aruanne, tahvlid ja toimik.
  • Võrdlusalus, edetabel ja artikkel: docs/ repositooriumis.

SetuHQ enda andmed, võrdlusalus, edetabel ja artikkel on litsentsi CC BY 4.0 all; kood on litsentsi AGPL-3.0 all (saadaval on ka kommertslitsents). Viidake sellele faili CITATION.cff abil.

Tehnilised üksikasjad: kust arvud pärinevad

Kandidaatide lehtedel on joonised salvestatud käivitustest (tess-wasp-126-s1, tess-toi-270-s5, tess-hd-15337-s4, tess-toi-236-s2, tess-pi-men-s1), tehtud praeguse koodiga.

Every number on the candidate and evidence pages is read from stored files: the run directory, the search catalogue and the calibrated reviewer weights. Runs and configuration lists the files, the configuration and its hash.

Selle lehe interaktiivsed osad ei laadinud. Ülalolev tekst on täielik; laadi uuesti, et uuesti proovida.
