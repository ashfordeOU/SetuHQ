Installatie en eerste run

SetuHQ vereist Python 3.11 of nieuwer.

pip install "setuhq[tess] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq run configs/showcase/tess-wasp-126-s1.toml --out runs/tess-wasp-126-s1   # or any star: copy a config, change its TIC and sectors
setuhq crossmatch runs/tess-wasp-126-s1          # the NASA Exoplanet Archive's planets for the star
setuhq site runs/tess-wasp-126-s1 --out site     # a website from your run (several runs: list them all)

Van elk voorbeeld op deze site staat de configuratie in configs/ en het commando van één regel in docs/SHOWCASE.md. De run downloadt de lichtcurve van MAST, schoont die op, laat het panel dips markeren, toetst elk signaal en schrijft elk resultaat weg met de herkomst ervan. De Probes draaien zonder account; de Sentinels hebben een API-sleutel voor hun provider nodig. Sentinels draaien standaard op Claude (Anthropic); andere providers worden ondersteund en gelabeld. Probes zijn deterministische matched-filterdetectoren.

Een sweep bijdragen

Een sweep doorzoekt elk 2-minuutdoel van een TESS-sector en bewaart elke dip die hij vindt, geclassificeerd, zonder iets weg te gooien. Je kunt een deel draaien en insturen:

setuhq sweep configs/sweep.toml --sector 5 --limit 200 --workers 3
setuhq bundle my-sweep/sector_0005.json.gz --contributor "Your Name" --out bundle/

Open a pull request with the bundle. A maintainer checks it and merges it into Everything that dims, with your name on every entry it brings. See CONTRIBUTING.md.

Gebruik vanuit een AI-assistent (MCP)

pip install "setuhq[tess,mcp] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq-mcp --list-tools

De installatie voor elke assistent staat in docs/MCP-INSTALL.md.

Data en bestanden

  • De catalogus van bekende planeten (JSON) en elke planeet op de Galaxy-kaart (CSV), van exoplanet.eu.
  • Alles wat dimt (JSON): elke vermelding uit de sweep van SetuHQ, met de bronvermelding.
  • WASP-126 (Hot Jupiter): het runrapport, de platen en het dossier van run tess-wasp-126-s1.
  • TOI-270 (Multi-planet system): het runrapport, de platen en het dossier van run tess-toi-270-s5.
  • HD 15337 (Small planets near the limit): het runrapport, de platen en het dossier van run tess-hd-15337-s4.
  • TOI-236 (Known false positive): het runrapport, de platen en het dossier van run tess-toi-236-s2.
  • pi Men (Reference check): het runrapport, de platen en het dossier van run tess-pi-men-s1.
  • De benchmark, de ranglijst en het artikel: docs/ in de repository.

De eigen data, benchmark, ranglijst en paper van SetuHQ vallen onder CC BY 4.0; de code valt onder de AGPL-3.0 (een commerciële licentie is beschikbaar). Citeer het met CITATION.cff.

Technische details: waar de cijfers vandaan komen

De kandidaatpagina's tonen figuren uit de opgeslagen runs (tess-wasp-126-s1, tess-toi-270-s5, tess-hd-15337-s4, tess-toi-236-s2, tess-pi-men-s1), gemaakt met de huidige code.

Every number on the candidate and evidence pages is read from stored files: the run directory, the search catalogue and the calibrated reviewer weights. Runs and configuration lists the files, the configuration and its hash.
