What each depth would imply, if it were a planet.

One card per star in the run or the feed. Each entry is a candidate, unconfirmed; the ratio below is what its stored depth implies if it were a planet.

Radius ratio only. Rp/R* = √depth, with depth as a fraction (ppm × 10⁻⁶). This assumes a full, undiluted transit and ignores limb darkening. No stellar radius is stored in the run or the catalogue, so this page does not convert the ratio to a planet radius in Earth or Jupiter units. Each bar is a ratio scale from 0 to 0.10, the same on every card.

Published planets come from the stored archive cross-match, which covers TIC 261136679. The other stars have no stored cross-match, so their cards have no archive box. Archive values only. This page claims no detection.

Silhouettes. Beside each ratio, the star in its blackbody colour (its TIC temperature, where the run stores one; grey where none is stored) with a black disc at Rp/R★ = √depth: the silhouette at Rp/R★ = √depth, if it were a planet. These are not planets, so none is drawn as one.
