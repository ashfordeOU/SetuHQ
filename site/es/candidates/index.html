Una caída que superó el vetting es un candidato, sin confirmar; una señalada sigue abierta; una rechazada no es un candidato. Ninguna es un planeta confirmado. SetuHQ's search batches run the same panel over more TESS stars. These entries are leads for review: 53 of 53 match a known TOI period, and none has a case file yet. A TOI match is an archive comparison. Archive values only. This page claims no detection. The feed shows only signals that match a known TOI. Las señales que no coinciden con ningún TOI conocido se retienen para una revisión privada; solo se publican tras su revisión y notificación.

Regla del feed. Una entrada se incorpora al feed cuando su profundidad es como máximo de 5000 ppm y su señal tiene al menos 2 tránsitos. Es una regla de admisión, no un resultado de verificación.
