Instalación y primera ejecución

SetuHQ necesita Python 3.11 o posterior.

pip install "setuhq[tess] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq run configs/showcase/tess-wasp-126-s1.toml --out runs/tess-wasp-126-s1   # or any star: copy a config, change its TIC and sectors
setuhq crossmatch runs/tess-wasp-126-s1          # the NASA Exoplanet Archive's planets for the star
setuhq site runs/tess-wasp-126-s1 --out site     # a website from your run (several runs: list them all)

Cada ejemplo de este sitio tiene su configuración en configs/ y su comando de una línea en docs/SHOWCASE.md. La ejecución descarga la curva de luz de MAST, la limpia, deja que el panel marque las caídas, verifica cada señal y escribe cada resultado con su procedencia. Los Probes se ejecutan sin cuenta; los Sentinels necesitan una clave de API de su proveedor. Los Sentinels se ejecutan con Claude (Anthropic) por defecto; se admiten otros proveedores, que se indican. Los Probes son detectores deterministas de filtro adaptado.

Aportar un barrido

Un barrido busca en cada objetivo de 2 minutos de un sector de TESS y conserva cada caída que encuentra, clasificada, sin descartar nada. Puedes ejecutar una porción y enviarla:

setuhq sweep configs/sweep.toml --sector 5 --limit 200 --workers 3
setuhq bundle my-sweep/sector_0005.json.gz --contributor "Your Name" --out bundle/

Open a pull request with the bundle. A maintainer checks it and merges it into Everything that dims, with your name on every entry it brings. See CONTRIBUTING.md.

Usarlo desde un asistente de IA (MCP)

pip install "setuhq[tess,mcp] @ git+https://github.com/ashfordeOU/SetuHQ"
setuhq-mcp --list-tools

La configuración para cada asistente está en docs/MCP-INSTALL.md.

Datos y archivos

  • El catálogo de planetas conocidos (JSON) y cada planeta del mapa de la Galaxia (CSV), de exoplanet.eu.
  • Todo lo que se atenúa (JSON): cada entrada del barrido de SetuHQ, con su crédito.
  • WASP-126 (Hot Jupiter): el informe de la ejecución, las láminas y el expediente de la ejecución tess-wasp-126-s1.
  • TOI-270 (Multi-planet system): el informe de la ejecución, las láminas y el expediente de la ejecución tess-toi-270-s5.
  • HD 15337 (Small planets near the limit): el informe de la ejecución, las láminas y el expediente de la ejecución tess-hd-15337-s4.
  • TOI-236 (Known false positive): el informe de la ejecución, las láminas y el expediente de la ejecución tess-toi-236-s2.
  • pi Men (Reference check): el informe de la ejecución, las láminas y el expediente de la ejecución tess-pi-men-s1.
  • El benchmark, la clasificación y el artículo: docs/ en el repositorio.

Los datos, el benchmark, la clasificación y el artículo propios de SetuHQ están bajo CC BY 4.0; el código está bajo la AGPL-3.0 (hay disponible una licencia comercial). Cítelo con CITATION.cff.

Detalles técnicos: de dónde salen las cifras

Las páginas de candidatos muestran figuras de las ejecuciones almacenadas (tess-wasp-126-s1, tess-toi-270-s5, tess-hd-15337-s4, tess-toi-236-s2, tess-pi-men-s1), generadas con el código actual.

Every number on the candidate and evidence pages is read from stored files: the run directory, the search catalogue and the calibrated reviewer weights. Runs and configuration lists the files, the configuration and its hash.
